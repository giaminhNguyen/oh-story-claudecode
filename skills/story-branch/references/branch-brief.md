# 分支简报规范

## 目标

将作者拍板选定的候选转化为结构化简报，供 `handoff` 子命令和写作工程使用。

## 输入

- `分支库/{源ID}/分支提案.md`（作者选定的候选编号）
- 作者对候选的补充说明或修改意向

## 简报字段

```markdown
# 分支简报：{分支ID}

## 基本信息
- 源ID：{源ID}
- 源作品：《{书名}》
- 分支ID：{分支ID}（如 SRC-001-B01）
- 创建时间：{日期}
- 基于候选：{候选N — 概念工作标题}

## 主角
{谁是这部分支的故事中心；与正典的关系}

## 前世 / 正典上下文
{主角在正典中的角色；他们知道什么；他们经历了什么}

## 知识边界
{主角在分支起点知道什么 / 不知道什么；知识的来源与局限；随分歧扩大时知识如何衰减}

## 分歧点
{第一个有意义的偏离点；与正典的区别；触发条件}

## 变更事实
{因分歧而改变的正典事实清单；哪些正典事件的前提已消失；哪些人物关系已重构}

## 分支专属世界规则（如有）
{如果引入了新规则，写明规则内容、一致性约束、产生的后果}

## 因果约束
{什么事情必须发生 / 不能发生以保持内部一致；对手的回应路径；盟友的激励变化}

## 故事方向
{新的核心冲突；主要张力来源；可能的升级路径}

## 交给写作工程的边界
- 这份简报不包含大纲、章节规划、字数口径、正文规则
- 正文方法论由 story-long-write / story-short-write 自带
- 简报是写作工程的输入材料，不是写作工程本身
```

## 落盘路径

`分支库/{源ID}/分支/{源ID}-B0X.md`（`0X` 从 01 开始，新建时取当前目录最大编号 + 1）

完成后提示作者：「分支简报已保存，输入 `/story-branch handoff 书名` 播种写作工程。」
