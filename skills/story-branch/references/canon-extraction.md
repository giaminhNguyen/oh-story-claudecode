# 正典提取指南

## 目标

从源作品中提取结构化的正典材料，供 explore 子命令使用。

## 提取范围

按以下维度系统提取。维度不是清单——目的是捕获对分支生成有价值的材料，而不是机械填写所有格。

### 人物清单

每个有名字的角色记录：
- 姓名与别称
- 立场（主角 / 对手 / 盟友 / 旁观 / 配角 / NPC）
- 动机（作品中呈现的）
- 掌握的关键信息（第几章获得 / 一直知道 / 从未知道）
- 与其他角色的实际关系（不是社会头衔，而是实际利害）
- 作品中未被充分利用的特质或地位

### 时间线与事件

- 主线事件顺序（可与章节号对应）
- 每个关键事件的因果触发条件
- 事件的不可逆后果
- 如果某件事没有发生，哪些后续事件会受影响

### 秘密与信息分布

记录每个重要秘密：
- 内容
- 在第几章被揭示
- 揭示前谁知道 / 谁不知道
- 若揭示时间改变，影响哪些人的行为

### 因果依赖

哪些事件依赖特定前提：
- 事件 A 发生的条件是什么
- 如果条件不满足，事件 A 是否仍会发生
- 哪个角色是事件的必要参与者

### 未解与缺口

- 作品中没有充分解释的动机或行为
- 读者在阅读时可能产生的合理问题，作品没有回答
- 配角的背景线索，但作品未展开
- 结局之后可能发生的后续

### 读者预设

阅读这部作品，读者很可能形成哪些默认假设：
- 谁是道德中心
- 谁是受害者 / 赢家 / 输家
- 结局是否正确
- 叙事者是否可靠

这些预设是 explore 阶段反转原材料的基础。

## 落盘格式

```markdown
# 正典：《{书名}》

- 源ID：{源ID}
- 提取时间：{日期}
- 章节范围：{来源}

## 人物清单
...

## 时间线与关键事件
...

## 秘密与信息分布
...

## 因果依赖
...

## 未解与缺口
...

## 读者预设
...
```

提取完成后提示作者：「正典已提取完毕，输入 `/story-branch explore` 生成分支候选。」
