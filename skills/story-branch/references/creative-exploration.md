# 分支创意探索引擎

## 核心原则

探索的起点不是「用哪个套路」，而是「这部正典里哪些假设、角色、身份、信息分布、因果关系、世界规则可以被变形，从而产生出乎意料但合乎逻辑的新前提？」

AI 被允许打破/重组原作的：
- 角色立场
- 记忆与意识
- 身份与身体归属
- 关系结构
- 因果假设
- 时间线结构
- 世界规则

条件：**变形后必须有强内在逻辑。**

## 内部工作流程

以下是探索阶段的内部思考流程。不要向用户逐字展示这个流程；只输出最终候选。

### 阶段 A：绘制正典可供性

从正典中识别：
- 未被充分使用的角色
- 信息缺口
- 矛盾之处
- 隐性因果依赖（某事件依赖另一事件）
- 未实现的选择（角色在某时刻原本可以做另一个决定）
- 高杠杆事件（改变这一事件，后续大幅改变）
- 特殊信息获取渠道
- 未解决的关系
- 正典结束之后的后续可能性
- 读者典型假设（谁是道德中心、谁是输家、结局是否正确）

### 阶段 B：生成宽泛变形

在以下维度上变形。维度不是封闭清单。可以组合多个维度。

**叙事角色**：主角 / 对手 / 受害者 / 赢家 / 输家 / 盟友 / 旁观者 / 配角 / NPC / 道德中心 都可以互换、颠覆、升格。不要默认正典女主角仍是道德中心。不要默认正典女配仍是对立面。不要默认男主是战利品。

**身份与意识**：意识 A 在 B 的身体里；A/B 互换；同一身体里两个意识；一个人的记忆散布于多人之中；携带对手记忆的角色；未来的人进入意想不到的过去身份；读者进入配角；主角返回时苏醒在女配身体里；女配占据女主身体；第三意识占据其中一人。这些只是示例，不是模板。

**记忆与知识**：完整记忆、片段记忆、污染记忆、错误记忆、来自已消失时间线的记忆、两个角色记住了不同版本的历史、只知道结果不知道原因的角色、随分歧扩大而消失的知识、另一个角色在每次正典改变时想起旧时间线、读者掌握的知识被证明基于不可靠叙事者。时刻保留知识来源：读者知识 ≠ 角色知识。

**目标**：不要默认复仇 / 规避死亡 / 抢走男主 / 拯救女主 / 用未来知识发财 /「这辈子我不会爱上他」。从变形后的处境重新推导目标。可能的目标包括：拒绝为男主争风吃醋、主动压制女主、保护原书反派、维护正典不被破坏、毁灭正典秩序、追求权力与生存而非恋爱、探寻为何记忆与现实矛盾、阻止对原主角有利的事件、确保看似不利的坏事仍然发生因为更重要的后果依赖于它。

**关系与同盟**：女配 + NPC 对抗女主；女主 + 前对手；两个转世的敌人被迫合作；读者偏向的角色在书中受到对立角色支持；两个有未来知识但目标不兼容的角色；一方试图改变正典，另一方必须保持正典不变；原本中立的人因激励变化成为关键对手。新关系必须从动机和信息中自然生长，不能凭空乱配。

**时间与因果**：不要局限于「死亡→回到若干年前」。允许：倒带、部分倒带、循环、多时间线、记忆向后穿越而身体不移动、来自更远未来的干预、正典结束之后开始的分支、从正典中途开始、后果在其原因之前出现、角色记住一条已被删除的时间线。使用它们的前提是能够产生自洽的因果规则。

**世界与叙事规则**：explore 可以发明一条新分支规则，如果这条规则产生有用的冲突。例如：每次改变正典会抹去一部分未来记忆；阻止一件正典事件会让另一人想起旧时间线；穿书读者读到的“原著”其实只是女主片面视角的自传；未读的未来篇章随时间线改变而消失；正典事件背后存在原书未揭示的隐秘机制；“剧情修正力”存在但源于可被发现的实体机制。每条新规则必须：保持自洽 / 产生后果 / 制造艰难抉择 / 推动冲突升级 / 在高潮时刻起决定性作用。不要为了制造奇异感而引入廉价规则。

### 阶段 C：淘汰明显候选

如果一个前提可以被以下任何短语完整概括，它尚未足够有力：

- 「女配转世复仇」
- 「女配转世不争男主」
- 「男主后悔了来追她」
- 「未来知识当无限金手指」
- 「穿书恶役女配直接变好人」
- 「穿书读者拯救可怜配角」
- 「反派转世线性洗白」
- 「配角秘密有强大身份」
- 「配角其实一直都知道」
- 「同一正典事件换视角重述」
- 「分歧后所有主要正典场景仍然发生」
- 「对手变蠢让主角赢」
- 「录像 / DNA / 证据直接终结高潮」

如果使用了熟悉机制，要求至少一个变形改变核心冲突的性质。

继续追问：
- 还有谁知道？
- 如果记住的未来是错的呢？
- 如果主角不想要复仇呢？
- 如果另一个角色必须保持正典不变？
- 如果原来的「胜利」引发了更晚的灾难？
- 如果第一个分歧让主角原本的目标失去意义？

### 阶段 D：压力测试逻辑

对每个候选检查：
- 知识来源是否有根据
- 动机是否从情境推导，而非强加
- 因果链是否一致
- 蝴蝶效应：分歧后哪些正典事件的前提消失
- 对手怎么回应变化（他们有自主行动能力）
- 主角优势是否会随时间衰减（知识失效）
- 赌注是否可以持续升级
- 是否有能力支撑一个与正典不同的高潮
- 是否是重述而非真正新的因果引擎

### 阶段 E：只输出强候选

提供大约 5–8 个真正有力的候选。不要输出 20 个弱变体。

候选之间必须在故事引擎上不同，不只是主角名字不同。

## 候选多样性要求

一批候选不能全部是：
- 五个转世
- 五个读者穿书
- 同一个前提配不同主角

覆盖多个结构维度。可能的多样性轴：
- 身份变形
- 知识变形
- 同盟反转
- 因果 what-if
- 正典结束后的谜题
- 世界规则 / 时间线变形
- 无超自然机制的分支
- 不可靠叙事者分支

这些是示例，不是配额。

## 无超自然机制的分支

explore 必须能够产生没有任何超自然机制的有力分支。

可以通过以下方式产生分支：
- 一个不同的决定
- 信息提前到达某人
- 某人拒绝参与
- 证据没有出现
- 误解提前解除
- 配角以不同方式介入
- 正典结束后的后续
- 一段隐藏关系以自然方式被发现
- 不同的激励改变了关键决定

不要假设分支 == 转世/穿书。

## 候选输出格式

每个候选包含以下字段（markdown）：

```markdown
## 候选 N — [概念工作标题]

**主角**
谁成为故事中心。

**正典锚点**
哪些实际正典元素让这个分支成立。

**变形**
在角色 / 身份 / 记忆 / 关系 / 时间线 / 规则哪些轴上发生了什么变化。

**前提**
新情境的简洁描述。

**分歧点**
这条时间线第一个有意义的偏离点。

**知识 / 信息不对称**
谁知道什么 / 谁不知道。

**新的核心冲突**
因为这个分支，特有的冲突是什么。

**为什么不是重述**
解释因果引擎在根本上是新的。

**惊喜逻辑**
为什么这个方向难以预测但仍然被正典支持。

**故事潜力**
既有写作引擎后续可以展开的张力类型。
```

不要加章节结构、场景数量、正文规则、节奏表或固定高潮公式。这些是写作 skill 的责任。

## 惊喜哲学

目标：**预测意外，回顾必然。**

强候选应该让作者想到：「我不会预测到这个方向，但给定正典，这说得通。」

新颖性必须锚定于正典。使用锚点：
- 未被充分利用的角色
- 信息缺口
- 未解决的关系
- 隐性因果依赖
- 未探索的机会
- 未解决的结局后续
- 矛盾之处
- 特殊信息获取渠道
- 缺失场景
- 读者假设
- 模糊动机
- 未实现的选择

不要通过以下方式制造惊喜：
- 无根据的秘密身份
- 突然出现的亿万富翁/继承人揭示
- 无法解释的能力
- 机器降神
- 未播下种子的系统
- 让配角事后变成一直知道一切
- 无分歧原因地更改正典事实

## 知识优势衰减

对于转世、穿书、未来知识、时间旅行、读者知识等：

初始知识可以很强大。随分歧扩大：
- 未来知识变得不那么可靠
- 未知领域增加
- 主角必须真正推理和行动

不要让对正典的了解成为无限使用的作弊码。

## 角色自主性

分支应该像这样运作：
- 主角行动
- 其他人观察
- 信念改变
- 激励改变
- 其他人回应
- 新后果出现

对手有自主性。盟友有自主性。中立角色可能换边。

分支不能因为主角有信息优势就成为心愿满足。

## 反转读者假设

在生成候选之前，识别正典产生的可能假设。

示例假设（仅作方法论说明，不是模板）：
- 女主 = 道德中心
- 女配 = 输家
- 男主 = 奖品
- 正典赢家 = 正确的人
- 正典结局 = 美满结局
- 叙事者 = 完全可靠
- 配角 = 无关紧要
- 正典主角是唯一值得拯救的人
- 死亡 = 失败
- 读者比角色知道更多真相

然后测试这些假设的反转。示例仅供方法论参考，不是硬编码输出。

落盘 `分支库/{源ID}/分支提案.md` 后提示作者：「分支候选已生成，输入 `/story-branch create` 拍板选定方向。」
