# 分支交接规范

## 目标

将分支简报播种到目标写作工程目录，然后交给既有写作流程。

**这一步只生成设定材料，不写正文，不新增写作方法论。**

## 输入

- `分支库/{源ID}/分支/{分支ID}.md`（目标简报）
- 目标书目录名称（作者提供）

## Step 1：确认目标工程

1. 确认作者指定的书目录
2. 如果书目录不存在，询问是否新建（新建时建空目录，不初始化完整结构；初始化由 story-setup / story-long-write 负责）
3. 如果书目录已存在，检查是否有 `.story-deployed` 标记；有则提示是否在已有工程中添加分支设定

## Step 2：写入分支设定

生成 `{书名}/设定/分支设定.md`：

```markdown
# 分支设定：{分支ID}

> 本文件由 story-branch handoff 生成。正文、大纲、字数口径由写作 skill 自带。

## 源作品
《{源作品书名}》（参考 `分支库/{源ID}/正典.md`）

## 主角
{来自简报}

## 前世 / 正典上下文
{来自简报}

## 知识边界
{来自简报}

## 分歧点
{来自简报}

## 变更事实
{来自简报}

## 分支专属规则（如有）
{来自简报}

## 因果约束
{来自简报}

## 故事方向
{来自简报}
```

## Step 3：写入交接备忘

生成 `{书名}/.story/work/分支交接.md`（目录不存在则建）：

```markdown
# 分支交接备忘：{分支ID}

- 生成时间：{日期}
- 分支简报：`分支库/{源ID}/分支/{分支ID}.md`
- 分支设定：`{书名}/设定/分支设定.md`

## 下一步

写作工程准备好后，运行：
- `/story-long-write 开书`（长篇）
- `/story-short-write`（短篇）

写作 skill 会读取 `设定/分支设定.md` 作为初始设定输入。
```

## Step 4：汇报

向作者汇报：
- 已创建的文件
- 下一步操作（setup 环境 → 开书）
- 如果项目未部署过，提示先运行 `/story-setup`

## 注意事项

- 不要触碰 `正文/`、`大纲/`、`追踪/` 目录
- 不要生成章节大纲或卷纲
- 不要修改已有的 `设定/` 文件（如果已有 `设定/分支设定.md`，提示作者确认是否覆盖）
- 不要调用写作 skill 的内部脚本
